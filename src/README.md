# מדריך לימוד — ביקורת מתקדמת ב'

אתר סטטי בקובץ HTML יחיד (`index.html`, עברית RTL, מותאם למובייל) לקורס "ביקורת מתקדמת ב'" (ד״ר אלון כהן, אונו, קוד 6210): הסברים לפי התקנים והחוקים, ציטוטים עם מספרי סעיפים, ושאלות מבחינות המועצה והמכללה עם הפתרון הרשמי.

## מקורות
- חוברת הקורס, קובץ התקנים (1, 220, 240, 250, 540, 545, 610, 920 והנחיית המיסים), חוק ניירות ערך, חוק הביקורת הפנימית וחוק החברות.
- בחינות המועצה (23 מועדים, 2015–2025) ובחינות המכללה, עם הפתרונות הרשמיים.
- מיפוי שאלות המועצה של המרצה. שאלות שסומנו "לא במיפוי" נוספו בסריקה של כל מועדי המועצה ואינן חלק מהמיפוי.

במקרה של סתירה — נוסח התקן והחוק קובע. קבצי המקור (PDF, טקסט מחולץ, שקפים) אינם כלולים במאגר.

## בנייה מחדש
```
python build/merge.py        # ממזג את קבצי השאלות והמיפוי אל content/cases.json, mapping.json, exams.json
node build.mjs               # מייצר dist/index.html   (קודם: npm install)
node fixtures/check_html.mjs dist/index.html   # בדיקת מבנה
```
`merge.py` קורא את תיקיית `analysis/` (קבצי `cases_*.json`, `extra_parts_*.json`, `mapping.json`, `exam_meta_*.json`) שנמצאת רק בסביבת העבודה המלאה; במאגר זה `content/*.json` הם הקלט המוכן ל־`build.mjs`.

## מבנה התיקיות
```
index.html          התוצר המוכן לפרסום
vercel.json         הגדרת אתר סטטי
src/
  build.mjs         מחולל האתר
  *.css, *.js       עיצוב ותסריטי דפדפן שמוטמעים בקובץ
  content/*.json    תוכן הפרקים, השאלות (cases.json), המיפוי והבחינות
  fixtures/         בדיקות מבנה
  build/            merge.py, check_text.py
```
